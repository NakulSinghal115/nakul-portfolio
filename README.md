# Nakul’s Portfolio

A responsive, single-page portfolio inspired by the reference site’s dark technology aesthetic. The layout and copy are original. Everything personal is kept in one file so it is easy to update.

## Personalize it

1. Open `content.js` in any text editor.
2. Replace the sample text in `window.PORTFOLIO` with your name, role, location, short bio, About copy, skills, projects, email, and social URLs.
3. Delete skill or project entries you do not need, or duplicate an entry to add another.
4. Leave a social `url` blank to hide that link. Add a project `url` to make its row clickable.
5. Open `index.html` in a browser to preview the site.

The project uses plain HTML, CSS, and JavaScript; it has no build step or dependencies. To publish with GitHub Pages, create a repository, add these files at the repository root, then enable Pages in the repository settings. A custom domain can be configured later if desired.
